StudyPad API 用法

study.lovecacx.icu 对外接口一览：进度查询 · OpenClaw 接入 · AI 使用方法

快速开始 字段参考 其他接口 接入 OpenClaw AI 使用方法

① 快速开始 · 进度查询

无需登录：浏览器直接访问 /你的用户名=你的密码 即可查看排版好的进度页（打卡进度 + 英语进度 + 今日需学/待复习/已学 + 全部单词本）。

https://study.lovecacx.icu/你的用户名=你的密码

程序调用（curl / 脚本 / AI 助手）返回 JSON：

curl -s "https://study.lovecacx.icu/你的用户名=你的密码"

可选参数：?pretty=1 缩进 JSON（人看）· ?json=1 强制 JSON（浏览器下跳过进度页视图）。

⚠ 密码会留在浏览器历史 / 命令记录里，建议单独设一个低敏密码，勿用重要密码。

② 返回字段参考

访问GET /用户名=密码（即本站地址 + 账号）——程序访问返回 JSON；浏览器打开显示进度页
鉴权用户名+密码与登录一致（scrypt 校验），错误返回 401 {"error":"用户名或密码错误"}；密码含 = 时按第一个 = 拆分

checkin —— 打卡学习进度

day / status当前天数 / 「Day N」「未启程」「已结束」
phase / sub当前阶段与子阶段（如 1.1 筑基起步）
start / today开学日期 / 服务器今日日期（yyyy-mm-dd）
doneN / total / percent已打卡任务数 / 全周期 596 / 百分比
done已打卡任务 id 数组（排序）

english —— 英语学习进度

统计words 词库数 · strong 已巩固 · learning 学习中 · fresh 生词 · due 待复习 · answers{ok,ng} 累计对错
词书bookCursor 游标 / 1506 · dailyNew 每日新词量 · today{n,r} 今日新学/复习 · days 记录天数 · newSum/reviewSum 累计 · dailyLog 每日日志全量
todayNew今日需学单词 [{w, idx}]——从词书游标起 ≤dailyNew 个未收录词（与站内页逻辑同口径）
todayLearned今日已学 [{w, s, due?}]——今天新收进词库的词
dueWords今日待复习 [{w, s, due}]——到期词，按到期日升序
book全部单词本 1506 词（按《樱日常》文章顺序），每词 {w, s, due?}
extra词书外收录的词（故事专名等）

单词状态 s：未学习 / 待复习 / 第N轮 / 已巩固；due 为到期日 yyyy-mm-dd（已巩固不带）。

③ 其他接口

GET /api/users公开：全部用户昵称与已背词数 vc（打卡页同学面板用）
GET /api/visits?page=key公开：页面浏览量（POST /api/visits 自增）
GET /api/avatar/:username公开：用户头像图片
登录态接口POST /api/register · /api/login · /api/logout · GET /api/me · POST /api/progress · GET/POST /api/vocab · GET /api/vocab/due——需先登录拿 Cookie 会话，供站内页面使用

④ 接入 OpenClaw

OpenClaw（开源个人 AI 助手，原 Clawdbot / Moltbot）可以接微信 / Telegram / WhatsApp 等聊天软件，支持自定义技能（Skill）和定时任务（cron）。把它接入本站后，你可以直接在聊天里问「我的学习进度怎么样」，或让 AI 每天早上自动播报今日任务。

第 1 步：新建技能

在 ~/.openclaw/skills/ 下新建 studypad/ 目录，写入 SKILL.md：

---
name: studypad
description: 查询体育单招备考站的学习进度（打卡 + 英语单词）
---

# StudyPad 进度查询

当用户问「我的学习进度 / 打卡 / 单词情况」时：

1. 运行：curl -s "https://study.lovecacx.icu/你的用户名=你的密码?json=1"
2. 根据返回 JSON 回答：
   - 打卡：checkin.status / phase / doneN / percent
   - 今日任务：english.todayNew（需学）、english.dueWords（待复习）
   - 词库：english.strong 已巩固 / learning 学习中 / fresh 生词
3. 字段含义见 https://study.lovecacx.icu/api/

第 2 步：对话中使用

重启 OpenClaw 后直接说：「用 studypad 查一下我的学习进度」「我今天要背哪些单词？」

第 3 步（可选）：每天定时播报

openclaw cron add --name "studypad-morning" \
  --schedule "0 8 * * *" \
  --prompt "用 studypad 技能查询我的学习进度，把今日需学单词和待复习单词列出来，用一句话鼓励我开始学习"

命令以你安装的 OpenClaw 版本文档为准；技能里的账号密码请妥善保管。

⑤ AI 使用方法

方法一：把 JSON 直接喂给 AI

打开进度页链接加 ?pretty=1，复制 JSON，粘贴给任意 AI（Claude / ChatGPT / 豆包…）配上这段话：

你是我的备考教练。下面是我学习站的实时进度 JSON：
（粘贴这里）
请：1) 一句话点评我的打卡状态
    2) 列出我今天的任务（需学 + 待复习）
    3) 结合 dueWords 给一个 30 分钟复习顺序
    4) 根据正确率（answers.ok/ng）给一条改进建议

方法二：命令行 + jq 提取

# 打卡百分比
curl -s "https://study.lovecacx.icu/用户名=密码" | jq '.checkin.percent'
# 今日待复习的单词（每行一个）
curl -s "https://study.lovecacx.icu/用户名=密码" | jq -r '.english.dueWords[].w'
# 今日需学前 5 个
curl -s "https://study.lovecacx.icu/用户名=密码" | jq -r '.english.todayNew[].w' | head -5

方法三：手机自动化

iOS 快捷指令 / Android Tasker / MacroDropy 定时执行 GET 请求，把 todayNew、dueWords 解析成系统通知——每天早上自动提醒今日任务。

方法四：周报生成

接口里的 dailyLog（每日新学/复习量全量）+ days（连续记录天数）可以让 AI 生成学习周报、趋势分析和下一阶段计划。
