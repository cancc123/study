# StudyPad · 体育单招备考学习网站

个人备考用的全栈学习站点：打卡督促 + 单词记忆 + 配套阅读 + 语文复习 + 数据统计，一站式覆盖体育单招文化课日常学习。

> 线上入口：`https://study.lovecacx.icu/`（仓库为私有部署，服务端与数据均自托管）

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 每日打卡 | 学习日历、连续天数、当日学习时长与词量汇总 |
| 单词背诵 | 1506 词书（《樱日常》36 章剧情序），**三轮任务交错流**：认词 → 辨析 → 巩固，配词组卡、美音 TTS 朗读、词形还原查询（aches→ache） |
| 阅读理解 | 与词书一一对应的 36 章英文故事，逐段中文翻译，点词查义、整句/全文朗读 |
| 语文复习 | 教材知识块化浏览、位置记忆（下次打开续读） |
| 统计面板 | 词汇量增长、复习到期曲线、学习时长分布 |
| 多主题界面 | 漫舞彩虹（默认）/ 樱花 / 茉莉奶绿 / 柳绿朝烟，液态玻璃 + 磨砂质感，选择跨标签页同步 |
| 进度 API | 学习进度结构化输出（今日新词 / 已学 / 待复习 / 完整词本），支持脚本与 AI 助手接入 |

## 使用方法

1. **注册登录**：访问站点，首页注册账号后登录；数据全部存在自托管服务端，换设备登录即恢复。
2. **每日学习**：进入单词页「今日」标签，点「开始学习」完成当日新词配额；有到期词时会出现「复习 N」按钮，单独刷复习。
3. **三轮记忆流**：每个词按 认词（四选一）→ 详解例句 → 拼写辨析 三轮交错进行；中途点「记错了」会把该词重新排到队尾再来一遍，全对才算巩固。
4. **查词**：阅读页与例句卡里**点击任意单词**即可弹出释义气泡，点喇叭可听发音。
5. **复习节奏**：学过的词按间隔到期（巩固等级越高间隔越长），首页与「待复习」分类会提示当日到期词。
6. **进度 API**：浏览器访问 `/用户名=密码` 看排版好的进度页，加 `?json=1` 返回 JSON；接入文档见站内 `/api` 页面（含 OpenClaw/AI 教练接入教程）。

## 部署

```bash
npm install        # 安装依赖（仅 Node 原生模块，无重型框架）
node server.js     # 启动服务：HTTPS :8084 / HTTP :8085 自动跳转
```

- HTTPS 证书放 `ssl/`（不入库）；注册用户、词库、头像等运行时数据存 `data/`（不入库，请自行备份）。
- 前端为无构建原生前端（HTML/CSS/JS），改完刷新即生效；公网入口经内网穿透映射 443 → 8084。
- 配套 **Android 客户端（StudyPad APK）** 在独立私有仓库维护，通过内容热更新包与本站同步。
